S'ENTRAÎNER AU CALCUL

Exercices corrigés pas à pas

Méthode professionnelle : données → hypothèses → charges → combinaisons → calcul → vérifications → conclusion.

🧱 Exercice 1 — Poutre simplement appuyée

Énoncé : poutre de portée L = 5,00 m soumise à une charge uniformément répartie q = 20 kN/m. Calculer le moment maximal et l'effort tranchant maximal.

Étape 1 — Modèle : poutre isostatique simplement appuyée.

Étape 2 — Effort tranchant : Vmax = qL/2 = 20×5/2 = 50 kN.

Étape 3 — Moment : Mmax = qL²/8 = 20×5²/8 = 62,50 kN·m.

Étape 4 — Suite du dimensionnement : le ferraillage et les vérifications doivent être réalisés selon le référentiel contractuel applicable et les caractéristiques réelles des matériaux.

🏢 Exercice 2 — Dalle pleine unidirectionnelle

Données : portée 4,00 m ; charge totale de calcul q = 8 kN/m² ; bande de calcul de 1,00 m.

Étape 1 : charge linéaire ql = 8×1 = 8 kN/m.

Étape 2 : Mmax = qlL²/8 = 8×16/8 = 16 kN·m/m.

Étape 3 : utiliser ce moment pour déterminer les armatures puis vérifier cisaillement, flèche et dispositions constructives.

🏗️ Exercice 3 — Semelle isolée : estimation de surface

Données : effort vertical de service N = 900 kN ; contrainte admissible du sol supposée σadm = 200 kN/m².

Étape 1 : S = N/σadm = 900/200 = 4,50 m².

Étape 2 : pour une semelle carrée théorique : a = √4,50 ≈ 2,12 m.

Étape 3 : cette valeur n'est qu'un point de départ ; vérifier ensuite la pression réelle, flexion, cisaillement, poinçonnement et tassements avec les données géotechniques.

Note technique : les exercices sont pédagogiques. Les valeurs de coefficients et les combinaisons définitives doivent être adaptées au règlement et au projet concernés.
